# AgriNet Client

フロントエンドアプリケーションです。
Nuxt 4 + Vue 3 + TypeScript を使用しています。

## 使用技術

- Nuxt 4
- Vue 3
- TypeScript
- Biome

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev
```

デフォルトでは

http://localhost:3001

で起動します。

## ビルド

```bash
npm run build
```

## ディレクトリ構成

app/
├── assets/
